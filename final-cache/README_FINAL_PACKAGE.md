To show the project live on the Windows machine where it was built:

1. Install/enable WSL with GCC. Python 3 is required; the live native demo itself needs only Python standard library on Windows.
2. In this folder run `python demo_hybrid_final.py` to verify the current four-stream results.
3. Run `python demo_hybrid_final.py --live calgary` to compile and run a fresh Linux direct-I/O demonstration. Its exact read counts and checksum should match; wall time can vary.
4. Show `hybrid_cache_evidence_bw.png` for the read-count and timing comparison, and `final_review_materials/output/frozen_model_diagnostics_bw.png` for classifier discrimination and calibration.

For retraining or regenerating the figure, install `requirements_final_cache.txt` in a Python environment.
