Improved adaptive chunk scheduler

One online tree decision, then bulk dispatch · Linux measurements

The one-decision version reduces synchronization and was faster than the previous repeated-round tree in this paired experiment. It did not beat the best fixed or standard-library option in every workload. This is application-level scheduling, not a Linux kernel patch.

175 timed runs in 25 paired workload/seed groups; 7 methods; matching checksums; PASS data audit. Each run includes worker startup, dispatch, inference and teardown.
