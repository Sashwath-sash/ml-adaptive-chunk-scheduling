Actual learned rule

Validation selected depth 1 and minimum leaf 8 from 25 CART configurations. If p90_to_mean ≤ 2.6845, select lpt_2; otherwise select lpt_4. The final test selected {'lpt_2': 42, 'lpt_4': 18}. This rule was learned from measured complete-run labels; LPT itself is a classical heuristic, not our invention.

Protocol, limitations and files

Training: four seeds per workload at two scales, two timed repetitions per candidate. Validation: three disjoint seeds at a third scale, two repetitions. Final: ten further unseen seeds at a fourth scale, randomized method order within each task group. Six generated workload classes include a real C prime-counting kernel; the others use deterministic C CPU work and a constructed tail-straggler. This is one WSL2 host, not production traces or a cross-platform guarantee. Standard Python APIs have different dispatch internals; comparisons are practical end-to-end results, not identical scheduler overhead microbenchmarks.
